# The run journal

Written by each run session before its relay, whenever it learned something that would make the next run go better: what happened, and what the skill should do about it. A note a later session sharpens is rewritten in place, never answered with a second one. Condense the file before it passes ~450 lines. A run's last bite distills the journal into the skill's other files and empties it back to this header. The first run's notes, with the evidence behind this skill's rules, are behind `@.claude/skills/megabeast/retired.md`.
