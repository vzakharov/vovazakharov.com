## API

`cube.ts`

```ts
const FACES = ['px', 'nx', 'py', 'ny', 'pz', 'nz'] as const;
type Face = (typeof FACES)[number];        // sign + world axis of the normal
type WithFace = { readonly face: Face };
type FacePoint = WithFace & { readonly u: number; readonly v: number }; // each in [−1, 1]
function faceToSphere(face: Face, u: number, v: number): Vec3;  // unit vector
function sphereToFace(p: Vec3): FacePoint;  // any length but zero
// internal but exported from the module (not the barrel): Axis, FaceFrame, FACE_FRAMES
```

- Face coordinates are **`u`, `v`**, not the design's `a`, `b`: a `{ a, b }`
  shape collides in `pnpm type-overlap` with origami's `Wings`. `u` runs along
  the frame's `U` axis, `v` along `V`; frames are right-handed (`U × V = n`).
- Frames: `px` n=+X, U=−Z (east), V=+Y (north) — so on `px` near Greenwich `u`
  is east, `v` north. `nx` U=+Z V=+Y; `pz` U=+X V=+Y; `nz` U=−X V=+Y; `py` U=−Z
  V=−X; `ny` U=−Z V=+X.
- `sphereToFace` on an edge or corner picks the first face in `FACES` order
  whose `|component|` ties for largest; an edge reads as exactly ±1.

`cube-edges.ts`

```ts
const DIRECTIONS = ['right', 'left', 'up', 'down'] as const; // right/left along u, up/down along v
type Direction = (typeof DIRECTIONS)[number];
type WithBack = { readonly back: Direction };
type Edge = WithFace & WithBack & { readonly flip: boolean };
type GridCell = PlanePoint & { readonly level: number };  // (x, y) in a 2^level grid
type CubeCell = GridCell & WithFace;  // x along u, y along v, both from 0 at −1
type Neighbour = CubeCell & WithBack;
const EDGES: Record<Face, Record<Direction, Edge>>;  // 24 transforms, derived from the frames
function edgePoint(face, direction, along: number): FacePoint;  // point at `along` on that edge
function crossEdge(face, direction, along: number): FacePoint;  // same point, beyond face's coords
function neighbour(cell: CubeCell, direction: Direction): Neighbour;
```

- `EDGES[f][d]` = the face beyond, the direction on it leading back, and whether
  the along-edge coordinate is negated there (`flip`; then cell index
  `k ↔ 2^level − 1 − k`). `neighbour(neighbour(c, d), back)` is `c`.
- Grid vertex `i` of level `l` is face coordinate `2i/2^l − 1` (exact in float);
  with it, the two faces' `faceToSphere` agree bit for bit on every shared
  vertex.

`geo.ts` — radians throughout, Greenwich on `+X`, longitude east toward `−Z`.

```ts
type LatLon = { readonly lat: number; readonly lon: number };
function latLonToUnit(place: LatLon): Vec3;
function unitToLatLon(p: Vec3): LatLon;   // any length; lon ∈ [−π, π], ±0 at a pole
function northAt(p: Vec3): Vec3;          // unit tangent; |lat| > 89.9999° → +X meridian's north
```

`northAt` at the North Pole is `(−1, 0, 0)`, at the South `(+1, 0, 0)`, each
projected onto the tangent plane at `p`. Degrees (the hook's `moveTo(lat°, …)`)
convert at the caller.

## Numbers

- Cell edge max/min on a 512² face, all six: **1.4142110665** (gate ≤ 1.415).
- Round trip face → sphere → face within 1e-12 on a 41² grid per face, edges
  included; sphere → face → sphere within 1e-12 on 3000 scattered directions.
- Bit-equality: 24 sides × 131,073 level-17 vertices, all equal. Dropping the
  `±1` special case in `slope` fails it at once (checked).
- The whole globe suite runs in ~0.7 s.
