# b3-s7 — step S7: look up and down (call 13)

Base 65da213d, branch `wt/b3-s7`. Done; additive to B5's sphere eye, all in
`src/island/features/eye/`. The planar game still runs, and still climbs on E/Q
and PageUp/PageDown.

## API

`model/look.ts` (new):

```ts
type Looked = { readonly look: number };          // radians raised above pitchAt(height); negative lowers
type Tilting = { readonly tilt: number;           // held, [-1, 1]
                 readonly nod: number };          // radians arrived since last frame
const UNTILTED: Tilting;
const TILT_RADIANS_PER_SECOND;                     // 80°/s, as the turn
const ABOVE_HORIZON;                               // 5°
dipAt(height)        // acos(R / (R + height)): the sea's horizon below the level
pitchFor(height, look)   // clamp(pitchAt(h) − look, dipAt(h) − ABOVE_HORIZON, π/2)
lookWithin(look, height) // look clamped to what pitchFor lets show at height
```

`model/globe-eye.ts`: `Eye` and its `aim` carry `look` (`eyeAt` opens at 0);
`Intent` is now the planar `Intent & Tilting`, and `STILL` is the planar `IDLE`
with the look's fields (the barrel exports `STILL`; `IDLE` was taken by the
planar eye, and `vova/no-export-namesake` forbids two). The aim's look moves by
`tilt · TILT_RADIANS_PER_SECOND · dt + nod`, then `lookWithin` the aim's height;
the eye's look eases toward it linearly by the same `toward` as the turn.
`model/globe-pose.ts` builds B5's pose, then turns forward and up about
screen-right by `pitchAt(h) − pitchFor(h, look)`.

## Keys and touch

- ↑/↓ tilt (held). E/Q and PageUp/PageDown climb and descend. ←/→ turn, WASD
  steer, as before. Keys taken: W A S D, ← → ↑ ↓, E Q, PageUp, PageDown. T,
  comma, period, [ and ] are free for call 12.
- **Touch**: two fingers moving together up or down tilt the view (up raises
  it), a drag up the whole screen height being 90°. One finger still moves;
  pinch still climbs; twist still turns. Two fingers no longer move the eye.
  Why: it is the convention Google Maps and Google Earth use for tilt, so
  players already know it, and it needs no button on the screen. Two-finger pan
  duplicated one-finger drag, so nothing is lost.
- **Mouse**: a right-button drag turns as it goes across (as before) and tilts
  as it goes up or down, as Google Earth's tilt drag does.

## Decisions

- **"A little above the horizon"** is the sea's geometric horizon, `dipAt`, not
  the level: from orbit the level points into space, 76° above the horizon.
- **The aim's look is clamped to its own height's range every step**, so a key
  held past a limit banks nothing to unwind. So climbing keeps the offset except
  where it would show past a limit: eyes lowered 60° at the ground come up to
  straight down at orbit, and stay there coming back down.
- **`pitchAt` is exported from `model/pose.ts`** (one word: B5 had already
  exported `poseFrom` there). Nothing else in the planar `eye.ts`/`pose.ts`
  changed. B8 moving `poseFrom` off the planar module takes `pitchAt` with it.
