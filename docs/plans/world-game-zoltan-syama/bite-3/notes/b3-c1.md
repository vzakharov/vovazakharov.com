## Decisions

- Calls 1 and 2 as recommended: shelves unioned, all 412 lakes removed. Caspian
  is sea (Eurasia's one hole).
- Column `j` reads as `360j/columns` folded into `[−180°, 180°)`, spans
  half-open `[west, east)`: the column at ±180° belongs to the polygon starting
  at −180°, so a pair split at the antimeridian shares no column and leaves no
  gap.
- An edge spanning > 180° of longitude throws (Natural Earth has none: 0 in all
  three layers) — except one along ±90°, which is a point on the sphere;
  Antarctica closes with 256 such edges.
- `earthMask` is async (the fetch) where the note wrote
  `earthMask(grid): Uint8Array`; the pure core is `layersMask`.
- Takes the full `RingGrid` (C2 has it from `fieldGrids`); a `Pick` of it is
  banned by `vova/no-pick-omit`.
