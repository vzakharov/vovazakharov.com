# b3-b5 — step B5: the eye on the sphere

Base ab5de1f57, branch `wt/b3-b5`. Done; additive — the game still runs the
planar eye. All in `src/island/features/eye/`.

## API

`model/globe-eye.ts` — same names as the planar `model/eye.ts`, so B7 swaps the
module. The barrel exports them aliased (`GlobeEye`, `globeEyeAt`,
`stepOnGlobe`, `withGlobeHeading`, `withGlobeHeight`, `globePoseOf`,
`GlobeGroundAt`) beside the planar ones; B7 drops the planar ones and the
aliases.

```ts
type Facing = { readonly at: Vec3 /* unit */; readonly ahead: Vec3 /* unit tangent at `at` */ };
type Poised = Facing & Elevated;
type Eye = Poised & Floored & { readonly aim: Poised };
type GroundAt = (p: Vec3) => number;                       // p unit
type Opening = LatLon & Elevated & { readonly heading?: number }; // radians, heading clockwise from north
const ISLAND_OPENING: Opening;   // unitToLatLon(planeToWorld(0, 0)), MAX_HEIGHT, heading 0
const EARTH_OPENING: Opening;    // 38° N 15° E, MAX_HEIGHT, heading 0
function openingOf(world: number): Opening;   // 0 → Earth, any other → ISLAND_OPENING
function eyeAt(place: Opening, groundAt: GroundAt): Eye;
function withHeight(eye: Eye, height: number): Eye;
function withHeading(eye: Eye, heading: number): Eye;   // radians from north; the hook's turnTo
function headingOf(eye: Eye): number;                   // [−π, π], clockwise from north
function step(eye: Eye, intent: Intent, dt: number, groundAt: GroundAt): Eye;
```

`model/globe-pose.ts`: `poseOf(eye: Eye, aspect: number): Pose` —
`position = at·(R + floor + height)`, built by
`poseFrom(position, ahead, height, aspect)` now exported from `model/pose.ts`
(the planar `poseOf` goes through it too).

`model/turns.ts` (slice-internal): `Turn = { axis, radians }`, `rotated`,
`turnBetween(from, to, fallback)` (least rotation; `fallback` axis when
antipodal), `partOf`, `signedAngle`, `tangent(v, at)`, `aheadAt(at, heading)`,
`headingAt(at, ahead)`. Headings go through `northAt`, so at a pole north is the
`+X` meridian's.

`model/eye.ts` now exports `Floored` (the `floor` member, shared by both eyes),
`clamp`, `easing`, `EASE_SECONDS`, `FLOOR_SECONDS`; `Intent`, `IDLE` and the
speed constants are the globe eye's too. When B7 retires the planar eye, these
stay.

## For B7

- Hook: `moveTo(lat°, lon°, m)` →
  `eyeAt({ lat: lat°·π/180, lon: …, height: m, heading: headingOf(from) }, groundAt)`;
  `turnTo(h)` → `withHeading`.
- `groundAt` takes a unit vector; the scene's ground sampler must read the
  sphere (B2/B3's).

## Decisions

- **The steer direction** is built in the eye's own frame (`ahead`,
  `ahead × at`) and carried to the aim by the least rotation from `at` to
  `aim.at` — the planar eye read `eye.heading` and moved the aim, so a drag
  follows what is seen.
- **Easing**: slerp `at` by `toward`, carrying `ahead`; the aim's facing is
  carried to the new `at` and `ahead` turns toward it by `toward` of the signed
  angle. The shorter way, so a single twist past π eases the short way round
  (the planar eye eased the whole twist). Held turns lag ~0.2 rad, far from π.
  `shortest` stays in `eye.ts` for the planar eye only.
- `openingOf` sends every world but #0 to #1's opening, as today.

## Numbers

- 55 eye tests (planar and globe) in ~0.3 s.
- Steer north from 80° N, 1,000 km up, 5 s: every frame on the start's great
  circle within 1e-9, `ahead` along the direction of travel within 1e-9;
  reaches > 89.9° and ends at λ + π, heading π.
- #1's opening pose equals the planar opening pose: position within 1e-6 m,
  forward and up within 1e-12.
- Easing after a kick (3,−2 heights, ×4, 2.5 rad twist): place within 1e-12 rad
  of aim, facing within 1e-9, height within 1e-9 relative, after 4 s.
