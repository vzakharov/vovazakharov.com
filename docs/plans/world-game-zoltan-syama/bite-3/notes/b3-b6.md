## Decisions / departures

- Per-degree scales, not b3-map's single `scale`: the clipped distance's
  spectrum falls by orders of magnitude over `l`, so one scale would spend most
  bits on nothing. Costs 512 numbers in the row.
- The fit writes the row only at the default clip, which the test re-fits.
- The script formats the row with prettier's API so `format:check` passes.
