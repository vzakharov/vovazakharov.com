# b2-s4 — the game on the world field, chosen by `#<N>`

Branch `wt/b2-s4`: `origin/island/worlds` + `origin/wt/b2-s1`.

## Done

- Worker: `init` carries `world` (decimal string); the worker builds
  `buildWorldField(world)` and `worldSeed(world)`, and its `built` reply sends
  the seed beside the field copy, so the main thread's `heightAt` takes the
  world's seed without loading the mask itself. `SEED` is gone (readers were the
  worker, `island-scene.ts`, `lowland.test.ts`).
- URL: `lib/world-hash.ts` `worldOfHash` (+ test) maps `location.hash` to a
  world, ours (`'1'`) for none or invalid. `island-canvas.tsx` reads it on mount
  and on `hashchange` calls `scene.setWorld`, which disposes the pool (workers
  terminated, queue and in-flight dropped), clears every held tile
  (`tileMeshes.clear`), and starts a new pool; the eye stays. A pool generation
  counter drops any late reply from a disposed pool.
- Call 10: nothing under `pages/**` or `entities/terrain/**` imports
  `entities/coast`. Moved: `tile-worker.ts`, `lowland.test.ts` (samples across
  `SQUARE` on `buildWorldField('1')`). `play-island.ts` and `film-descent.ts`
  never read the rings; they take `--world <N>` (files prefixed `world<N>-`;
  play-island drops the inlet shots off world 1).
