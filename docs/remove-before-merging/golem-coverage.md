# `/golem` coverage table

Every note in `.claude/skills/megabeast/notes/` mapped to the one `/golem` file that carries it, or to "dropped" with the reason. The review checks against it that nothing fell out; `/finalize` sweeps it.

**For a writer**: read only your own section. Each row is already the general lesson (game specifics turned into what any run needs, per the plan's "Game-only facts" paragraph); open the note by its source line only when you need its evidence. Rows marked "merge with" say the same thing from different bites, so they become one sentence. Nothing in a lesson is the skill's wording: say it in the skill's voice, in "see" and "use", with no stack named.

IDs: `R` README, `C` contract, `P` pickup-and-relay, `G` gates, `L` play-run-and-frames, `Q` quality, `S` subagents (each numbered in file order), `H` the #57 plan's § "How this elephant is eaten", `T` the PR #57 thread. A note carrying two lessons for two files is split `a`/`b`.
