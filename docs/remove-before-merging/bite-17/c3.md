# Package c3 — crickets (call 13)

## Done

- **Crickets and the birds at dusk** (branch `wt/c3`, landed as one squash
  commit on the shared branch):
  - `ui/scene/dusk-voice.ts`: `DuskVoice`, built as `RainVoice` — three
    crickets (4.3, 4.75, 5.1 kHz; panned -0.6, 0.15, 0.65), each a looping
    buffer of Hann-windowed 30 ms sine pulses, 3–4 to a chirp 45 ms apart,
    chirps 0.6–1.4 s apart from `mulberry32` seeds 17/29/43, nine chirps a
    loop (the loop is as long as its gaps, so the wrap is one of them). One
    gain at `level × CRICKET_LOUDNESS` (0.018: a pulse peaks about half a
    bird note's 0.035, under the rain's patter at 0.03).
    Pure halves with tests beside: `chirpRhythm`, `fillChirps`,
    `morningComes` (`dusk-voice.test.ts`).
  - `MeadowSound.dusk(level)`: builds the crickets on the first heard
    non-zero level, sets them each frame (free while still), lets them go at
    0, never builds them while hidden — the `shower` pattern. The scheduled
    day birds skip while `duskyAt(level)`; as a turn toward day passes
    `MORNING` (0.3) a phrase of three bird calls (0, 0.55, 1.3 s) plays.
  - `model/dusk.ts`: `duskyAt(level)`, the one home of the 0.5 threshold,
    which `dusky` now reads too.
  - `DuskView.update` calls `sound.dusk(level)`; `DuskSound` widened.
  - `sound.test.ts`: crickets built once / set only on change / let go;
    none while hidden; no scheduled bird at dusk, birds again by day; the
    morning phrase once per crossing.

## Verified

No sound probe exists (`__probe.eye().steps` only counts footsteps, and
reading a new one would need `play-dusk.ts`, which is another agent's), so
the voice is verified by the unit tests above. The `dusk` play was run on
tabL under the flock.

## Decided

- The chirp rhythm is baked into looping buffers rather than scheduled by a
  timer: it suspends with the context on a hidden tab, costs no frame work,
  and is a pure function to test.
- Morning's phrase plays only once the synth exists (a frame before the
  first tap greets nothing), and through `play`, so a hidden tab drops it.
