# Reference pool — «Ностальгия»

A reference is one of the operator's own catalogue masters whose REAPER project in its `vovas-music` repository (default branch) carries an iZotope Ozone 10 or 11 plugin. Scanned 149 repositories (every `repo:` in `apps/vova/public/music/songs/`) for `.rpp` files, any case, reading only those blobs; 113 carry Ozone in at least one project.

"Let the Stories Spin" is an album (GENERATED), not a song; its earliest tracks (gone-with-the-wind, mira-to-the-sea, other-heart, unforgiven-iv) are dated 2024-07-23, which is the cutoff used here. Its own title-ish repo `stories` (fireflies) has a project with no Ozone.

"Name match" means the project's file name matches the song's slug, repo, title or master source stem. Where a repository has several Ozone projects, the one listed is the name-matched one, else the one with full Ozone (not just Master Rebalance); "+N more" counts the others. "Catalogue master" is the file the site serves for download (FLAC, or the MP3 where the song is `lossy`), from `apps/vova/public/music/tag-renders.json`; "Master source" is the file the scaffolder read.
