# Тексты из Suno

Из публичного профиля [suno.com/@vova](https://suno.com/@vova): 55 клипов, текст есть у 45; дубли (две «Make Them Feel», две «Gray Rage», два «Ночных сада») сведены к одному. Это текст из запроса к Suno, а не транскрипция мастера: где слова потом переписывались, звучит другое.

Причёсано везде одинаково:

- убраны пометки для Suno — `[Verse]`, `[Solo]`, `[Riff]` и прочие;
- убраны ударения — знак над гласной (`кру́гом`) и заглавная гласная (`таИ́нственный`);
- исправлены написания «под произношение» — `виаланчЕ́лей` → «виолончелей», `тэмпе` → «темпе», `DISplay` → «display»;
- многоточия и разбивка по слогам, которыми Suno задавали паузы (`Be… my… slave…`), сведены к обычной пунктуации; повторы, которые поются, оставлены;
- стихи чужих авторов сверены с каноническим текстом, ё — везде.

Что исправлено сверх этого или вызывает вопрос — в строке «правки» под песней.
