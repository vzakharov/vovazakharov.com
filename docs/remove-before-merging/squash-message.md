```
The collections that grow as a stream had no way to be followed short
of revisiting the site. Bible articles (agentic.bible/feed.xml),
basilisk cases (basilisk.fyi/cases/feed.xml) and songs, one feed per
language (vovazakharov.com/music/{en,ru}/feed.xml), now each publish an
RSS 2.0 feed. Case studies and the basilisk FAQ do not: a portfolio of
one and reference pages edited in place are not streams.

A `feed` flag per collection in the registry decides which collections
publish one and derives each feed's address, and a test holds the
route files to it. Feeds are written at build time, as the sitemap is,
newest first by the date the sitemap reports; each item carries the
document's frontmatter blurb and a link rather than its full body,
which is rendered for the page and not for a feed reader.

Every page announces its site's feeds in `<head>` for reader
autodiscovery, and each feed is linked visibly from the footer of the
page whose listing it mirrors, after the copyright — which the music
page gains with it.
```
