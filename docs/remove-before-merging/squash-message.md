```
`next/font/google` downloaded Merriweather and JetBrains Mono from
Google Fonts on every `next build`, so a flaky gstatic response failed
the build — in vet and, equally, in the deploy on merge.

The faces are now committed under `src/shared/ui/fonts/` (Fontsource
5.3.0 woff2 with their OFL licences) and loaded through
`next/font/local`: Merriweather 300/400/700 and JetBrains Mono's
variable weight axis, in every subset Google served (Latin, Latin
Extended, Cyrillic, Cyrillic Extended, Vietnamese, and Greek for the
mono), behind the same CSS variables, with the Latin files preloaded
and a metric-matched fallback. A font changes only when someone
replaces a file.

Each subset is its own @font-face under one family name with the
subset's unicode-range, so a page downloads only the subsets its text
uses. Only Latin goes through next/font, which preloads it and sizes
the fallback; the rest are generated by a Sass loop. The font files
join PRINT_SOURCES, so every PDF is reprinted once in the vendored
faces.

Russian pages also preload Merriweather Cyrillic 400 and 700, so their
text no longer waits on the stylesheet to request it; English pages
load nothing extra. `pnpm check:font-preloads`, now in vet, opens
every Russian page in Chromium and fails when the preloaded set
differs from the files all of them actually use.
```
