```
The lint config was thirty lines of Next presets with Prettier
wired to run both inside ESLint and beside it, which left the
type-aware @typescript-eslint rules, the full jsx-a11y set and
every React-19 rule unenabled. At roughly 800 lines of source
across twelve files, adopting the explicit ruleset
playgramai/playgramapp runs is one pass here rather than the
migration it would be in a large codebase, so it lands whole
rather than softened.

eslint.config.ts, loaded via jiti, orchestrates the preset
spreads and plugin registration; the rules live in
eslint/rule-groups/*.ts split by plugin family, every one listed
as error or off — never warn — with each off carrying its
rationale. Nine of upstream's thirty project-local rules port
under a vova/ namespace, the rest assuming a database, server
actions, Mantine or Zod that a static export does not have.
tsconfig.json gains the twelve strictness flags several of those
offs delegate to, so the exemptions are real coverage rather
than silent gaps; eslint-plugin-prettier goes, since formatting
was checked twice and format:check was always the check doing
the work.

What it surfaced was mostly real. The theme toggle rendered an
English aria-label on the Russian CV, {stars && …} rendered a
bare 0, and three Spotify embeds had no title; the locale picker
carried the same English-label defect one step outside the
rule's reach, in a template expression rather than a literal.
i18n/messages.ts
now keys the catalogs by locale and registers them with
next-intl, so translation keys are checked, useMessages()
returns the catalog's real shape, and a key added to en.json but
not ru.json is a type error — which also retired eighteen
no-unsafe-* reports at their source by replacing t.raw(). The
eight PascalCase component files are kebab-case, moved with git
mv so history follows.

Two scoped off blocks carry their rationale rather than
softening a rule: consistent-type-definitions for the one file
that augments a library type, since declaration merging requires
an interface, and no-hardcoded-strings for the unlocalized root
page, which has no ru rendering for a literal to defeat. The
severity policy that governs both — error or off, grandfather
with a scoped off — is recorded in .claude/rules/eslint.md.
```
