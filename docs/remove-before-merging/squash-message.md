```
An album's or an artist's names, billing and glosses sat in TypeScript
registries beside the markdown file that already carried its prose and
hook, so one release was described in two places. Each album and artist
now has one file under apps/vova/public/music/, its frontmatter holding
what the registries held; a locale's title or name reuses a song's
field, a string renaming it there and { translation } glossing it.

A misspelt album or project in a song still fails the build: the song
schema reads the albums/ and artists/ directories and accepts only a
name a file there carries. MusicAlbum and MusicProject are zod brands
rather than literal unions, so neither passes for the other. A slug is
its file's name, and an album's cover is read off the covers directory
rather than stated.

The music index ranks its artists rather than keeping a hand-set order:
the one billed on the most songs first, between equals the one whose
latest song is newer. Every album and artist page links its .md, since
every one has a file.
```
