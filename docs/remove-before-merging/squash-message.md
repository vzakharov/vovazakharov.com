A song's REAPER project is where its arrangement lives, and the
vovas-music repositories hold one for 139 of the catalogue's songs.
Each of those songs gets a view-only DAW page beside its own, at
/music/songs/<slug>/project in both languages, linked from the song.

pnpm music:masters project vendors the song's project next to its
markdown as project.rpp, plugin state stripped: the one whose render
pattern made the master, or the one the song's new rpp: field names
where that is ambiguous. The build parses it with one tokenizer and
zod reader, shared with the script, so the page is server-rendered
and needs no network at build or at view.

The page draws the tracks with their colours, folders, mute and solo,
volume, pan and plugins; the items with fades and MIDI notes; the
tempo map, markers and regions, under a small client zoom. File paths
show by name only, never the author's disk layout. Waveforms and
playback are not drawn.
