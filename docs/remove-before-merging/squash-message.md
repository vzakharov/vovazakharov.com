PRINT_RASTER_DOMAINS (shared/lib/print-raster) lists such domains. A
source entry citing one, and any mention in a document body, carry a
print-raster class, and print puts a CSS filter on it: Chromium's PDF
backend paints a filtered element as a 300 dpi image, so neither its
text nor its links reach the file. The page on screen is unchanged.

A rasterized source entry loses its links in print, so a print-only
note under it sends the reader to the online version, whose URL the
footer already prints. The content rule names the "0 pages" symptom as
the cue to add a domain to the list.
