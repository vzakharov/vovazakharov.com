```
A PR could only be looked at locally or after it merged, and merging is
deploying. preview.vovazakharov.com is one hosted slot any branch can
publish any of the four sites to, so a change can be opened on a real
host, a phone or a reviewer's machine before it lands.

It is fed the way the other receivers are: a source-less repository,
vzakharov/preview.vovazakharov.com, whose gh-pages branch is one
force-pushed commit naming the site and ref it was built from, so it
holds no history and serves whichever publish came last.

publish-site.sh takes a --preview target that sends any site there and
writes the host's own files over the build's: a CNAME for the preview
domain, so a copy never claims a production one, and a robots.txt that
disallows everything. preview.yml dispatches it for one site from any
ref, in a concurrency group of its own, so it never touches or waits on
a production deploy. The /preview skill carries how to use it.
```
