# S5 — the scene

Done (typecheck, eslint, tests, check:masd, lint:fsd, check:poison green; NOT yet built or played):

- `lib/tile-worker.ts` — module worker: `init` builds the coast field (seed `SEED = 1`), `fill` posts `FilledTile { key, land: TileMesh & { colours } | null, sea: TileMesh | null, fillMs }` with buffers transferred (`filledBuffers`, built on `tileBuffers`). Sea = `fillTile(key, () => 0)`, the R sphere on the tile's own lattice; land skipped when the grid is all < 0, sea when all > 0.
- `lib/tile-pool.ts` — `POOL_SIZE = 2` workers (each holds its own ~22 MB field), ≤2 fills in flight each, queue replaced by `want(keys, x, y)` nearest-first; worker 0 sends a copy of its field for the main thread's `groundAt`.
- `lib/land-colour.ts` — height → linear RGB (sand/green/brown/pale), tested.
- `model/tile-cover.ts` — `coverOf(selected, has)` (missing tile → nearest held ancestor, which hides its loaded descendants, so no overlap/z-fight), `nearestFirst`, tested.
- `ui/tile-meshes.ts` — mesh cache by `tileId`, LRU eviction past 900, level-3 roots pinned, floating-origin placement `centre − eye` in float64.
- `ui/island-scene.ts` — `WebGPURenderer` (auto WebGL 2 fallback), `logarithmicDepthBuffer` (reversed depth needs `EXT_clip_control` on the WebGL backend), camera at origin, Lambert land (vertex colours) and sea, sun + hemisphere (sky set to local up), coarse globe at R − 1500 m for outside the square and before load, all 64 root tiles always requested, reselect when moved > 2 % of height, eye from `eyeAt({0,0,MAX_HEIGHT})`.
- `ui/play-hook.ts`, `ui/island-canvas.tsx` — hook only with `?play`, failures thrown to the error boundary.
