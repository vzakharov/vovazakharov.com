## Done (in `src/island/entities/terrain/`)

- `model/height.ts`: inland lowland floor — for `d > 0`, `smoothMax(h, f, f)` with `f = 15·(1 − e^(−d/5 km))`; zero on the coast, so the coastline (the field's zero line) does not move; sea side untouched. Exports `HIGHEST_GROUND`, `LOWEST_GROUND` (plateau/abyss ± sum of amplitudes) and `GROUND_SLOPE` (a loose analytic slope bound, ~7–8).
- `model/tile.ts`: `MIN_LEVEL`, `SPLIT_RATIO` moved here (from quadtree) so `detail.ts` can read them without a cycle; index re-exports them unchanged.
- `model/detail.ts` (new): `viewDistance(eye)` — the split rule's distance (eye to plane point at the eye's height clamped to the ground range), shared by the quadtree; `detailCut(eye)` → `(x, y) => metres`: `clamp(2·SPLIT_RATIO·D/cells, 2·spacing(MAX_LEVEL), 2·spacing(MIN_LEVEL))`. Why this and not geomorphing: it is ≥ the 2·spacing of the coarsest tile the selection can leave at that point (side ≤ SPLIT_RATIO·D for any unsplit leaf), so no leaf aliases, and it is a continuous function of position, so neighbours of any level cut the same octaves along a shared edge. Cost: up to one octave less than the old per-tile cut on tiles finer than the rule needs (coast-finer tiles, the far half of a level ring).
- `model/view.ts` (new): `Frustum = { sides: Vec3[] }`, `frustumOf(forward, up, fov, aspect)` (+0.1 rad margin), `outside(frustum, eye, points, slack)`. Positional args so no type duplicates `Pose`'s members (`pnpm type-overlap`).
- `model/quadtree.ts`: options now `{ coast?, frustum?, ground? }` (the unused `minLevel/maxLevel/splitRatio/lowest/highest` dropped: the detail cut depends on the constants). Per-tile relief from `ground` at 4 corners + centre ± `GROUND_SLOPE·side/2` (global range for big tiles / no sampler); horizon test uses the tile's own `high`; frustum test on the 8 border samples × {low, high}, slack = the sphere's bulge.
