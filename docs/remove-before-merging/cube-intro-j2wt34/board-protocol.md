# How the board is shared between the intro build and #275

Recovered 2026-11-13 from the first coordinator's reports. Two branches add to one artifact, https://claude.ai/artifact/WbvwDqVtJzN8EBeuUffho3; a publish from either alone would drop the other's items.

- **One publisher.** `claude/cube-intro-board` holds both sides' board commits and is the only place the artifact is published from. The #275 session (`session_01DaohkFooQx3YpuSjFHqR59`, branch `claude/cube-review-perf`) no longer publishes: after each board commit it sends "board: <sha>", and the coordinator cherry-picks it (minus the `.claude/costs/` row it carries), builds and publishes. The coordinator also fetches its branch on every wake, so a missed message costs delay only. Its fallback, if it must publish at once: overlay our files uncommitted, publish, remove them.
- **Separate files.** Our side lives in `src/cube-board/app/config/cube/intro.yaml`, `cube/intro-*.webp` (zone `z-intro`, x ≥ 5720) and `cube/rules.yaml` (zone `z-rules`, agreed with them). The coordinator edits none of their files; nobody pushes to the other's branch. A fix to their file (the `best-of.yaml` formatting, f659b195) is cherry-picked, and their next merge brings the same change clean.
- **Order and merges.** Their commits land on the board branch in the order they landed; the lead merges the board branch into the intro branch from time to time, so the board branch stays board-only commits.
- **Before every publish:** read the live artifact with `Artifact` `read`; list the artifact's `db` (`items`), and fold rows newer than the repo in as a `content:` commit of their own (empty at version 57).
- **Frames:** the lead commits images under `frames/` on its branch and messages file names, captions and the operator's verdicts; the coordinator converts to `.webp` (960 px, under 300 KB), numbers the captions, fills the timelapse zone, builds, publishes, pushes.
- **Operator comments:** all board text is English (the operator's rule: no Russian on the board). A comment that is a decision or a steer for the build goes to the lead verbatim at once, with a translation if it is not English.
- **Size guard:** `SCRIPT_BUDGET_KB = 120` in `src/board/scripts/board.ts` measures the script only; items do not count.
