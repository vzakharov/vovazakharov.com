# S1 — `mushroom-probe.ts` split

Pure refactor, no behaviour change: the 1031-line `scripts/lib/mushroom-probe.ts`
becomes five modules, every importer's import lines repointed (no barrel).

- `mushroom-probe.ts` — the page installs: `seededRandom`, `STEPPED_TWEENS`, and
  `PROBE`, composed as `(() => {${PROBE_INSTRUMENTS}  window.__probe = {${PROBE_READS}  };\n})()`.
- `mushroom-probe-instruments.ts` — `PROBE_INSTRUMENTS`, the page-side scene,
  timers and helpers (`toScreen`, `topAt`, `reaching`, …).
- `mushroom-probe-reads.ts` — `PROBE_READS`, the members of `window.__probe`;
  the one `${…}` splice (`PUFF_REACH.across`) moved with it.
- `mushroom-probe-answers.ts` — the zod schemas (`Clouds` now exported, for
  `tapCloud`).
- `mushroom-probe-drive.ts` — `Page`, `Expect`, the key tables, `FRAME_MS`
  and the moves (`walkAndTurn`, `grow`, `inTurn`, `tapCloud`, …).

Decided: the composed `PROBE`, `STEPPED_TWEENS` and `seededRandom(3)` were
checked byte-identical to the old module's under tsx before committing.

Done: typecheck, eslint, prettier, knip, type-overlap. Left: nothing.
