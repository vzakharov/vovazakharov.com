## Decided here

- `pnpm type-overlap` asked for four one-member bases: `Seeds` and
  `Parented` in `model/random.ts` (beside `Seeded`; `Chosen` and `BeeSown`
  now use them), `Stamped = { at }` in `model/motion.ts` (`planter.ts`'s
  `KeySown` uses it), `Reach = { reach }` in `model/geometry.ts`
  (`draw-insect.ts`'s `Reaching` uses it).
- An unknown or still-growing parent in a tick's shed grows nothing but
  still records the shower as shed.
- `sprouted` caps a shed at `SPROUTS` and re-checks `isFull`/`isCrowdedAt`
  per sprout against the meadow with the earlier ones added.
- `shedding` returns `undefined` (not an empty list) when no old mushroom
  is in sight, so the scene's per-frame check is one `undefined` test.
