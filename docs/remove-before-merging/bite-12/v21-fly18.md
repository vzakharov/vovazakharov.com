- The sight carries each drawn flier's own away spots: `Sight.aways`, by id
  (`model/flight.ts`), which `perches.sightFrom` builds with
  `awayPlaces(layout, view, away)` from the view's `awaysOf`
  (`insect-view.ts`, its `awayOf`: own wingspan, own phase's drop), passed in
  `meadow-scene.ts`'s `sightNow`. `placesSetOff` (`flight-timing.ts`) lays
  the flier's own spots over the sight's before timing, as it does `drawn`;
  a flier with none keeps the sight's band-middle spots. The model stays
  pure: the spots are input, as `drawn` is.
