## 4. Decisions

- **The floor below is drawn only under a hole.** `rooms.ts` splits `view`
  into `sight()` and `withBelow(seen, holeOf)`, so floor 66 loads and throws
  only once floor 66's hole comes within draw radius. The alternative, drawing
  all of the floor below, made floor 66 unloadable.
- **Keys work without pointer lock**, not in text fields, not with Ctrl/Cmd.
  W/S walk, A/D strafe, arrows turn (90°/s) and tilt (60°/s). The mouse looks
  only after click-to-lock. `Input` fields are `turnKeys`/`tiltKeys` because
  type-overlap rejected `turn`/`tilt`.
- **The `/cube` error page is deferred** on Вова's word; the generic Next page
  stays for now.
- **`roll.wide()` is two murmur3-32 words**, `WIDE_BITS = 64n`, `DEEPEST = 66`;
  the 64 is a habit, not a choice; the 67-floor ending rests on it.
