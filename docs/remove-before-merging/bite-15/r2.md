## R3's brief — the API `ui/scene/mouse-runs.ts` calls

Plane lengths in the clump's size, times in seconds. The scene holds a
`Mice` (`ReadonlyMap<id, count>`) and its runs; it never computes a rule.

- **Doors**: each frame build `RunDoor[]` = `{ id, foot, seen }` for every
  standing (`goneAt === Infinity`), doored (`HouseView.doored`) mushroom;
  `seen` = `stands` drawn and not `behind`.
- **Counts**: a new door → `entered(mice, id)`. A run's first frame →
  `left(mice, from)` (throws on an empty house — a bug, not a case); its end
  (`elapsed >= runDuration(course)`) → `entered(mice, to)`. Invariant:
  `miceHome(mice) + runs.length` is constant (bar sinking with no door left).
  An empty house (`miceAt === 0`) does not peek.
- **Outings**: per house keep the last `outingOf(now, phase)`; when it turns
  to `k`, if `runsOuting(mushroom, k, miceAt(mice, id))` and
  `runTarget(mice, door, doors)` gives `to`, start a run with
  `startedAt = outingStart(k, phase)`, `opening: 'peek'`. While that run is in
  its `peek` leg the house reads `out` from `runAt(...).headOut`, else
  from `peek`.
- **Door tap**: `answerTap(mice, door, doors)` → `run` (start now,
  `opening: 'peek'`, squeak), `call` (a run `from → tapped`, `calling: true`,
  squeak), `peek` (today's tap peek), `knock` (door opens on an empty doorway
  and shuts, `voice.knock`).
- **A run** = `{ from, to, startedAt, course: RunCourse }`,
  `RunCourse = { runLength, opening: 'peek' | 'leave' | 'run', calling }`,
  `runLength` = the distance between the two fronts at the start.
  Each frame: `m = runAt(now - startedAt, course)` gives `leg`, `progress`,
  `sill`, `bounce`, `headOut`, `fromOpen`, `toOpen`, `runner` (draw the
  runner graphics only while true), `travelled` (for the stride).
  A door's open = max of its peek's and every run's `fromOpen`/`toOpen` at it.
- **Where to draw**: `runnerAt(m, endOf(fromFront, fromDoorPlace, size),
endOf(toFront, toDoorPlace, size))` → `{ point, up, across, heading }`:
  the plane point (`standAt(bedPlace(view, point))`), the height off the
  ground and width (both plane lengths, scaled by depth), the unit plane
  heading (project it for the screen facing). A start that sank keeps its
  last front (freeze the `RunEnd`); a re-targeted run's start is
  `{ front: runner point, across: runner width, sillHeight: 0 }`.
- **Sinking** (`reconcile`'s loop): `scattered(mice, door, doors)` →
  `{ mice, fleeing }`: replace the counts, start a run per `fleeing`
  `{ to, wait }` at `now + wait`, `opening: 'leave'`. Those runs take no
  mouse off the counts (already gone). A run whose target sinks:
  `retarget(mice, runnerPoint, run.from, standingDoors)` → new run from the
  runner's point, `opening: 'run'`; `undefined` means no door stands.

## Decisions taken

- The run leg lasts `runLength / RUN_PACE` (call 8) with 0.15 s ease at each
  end, so its top pace is a little over `RUN_PACE` (≤ 5 %), its mean exactly.
- A sinking house's runs open at `leave` (no peek: the house sinks in 0.45 s).
- Counts move at the run's first frame and its last (door shut).
- Field names avoid `pnpm type-overlap` collisions: `progress` (spec's
  `along`), `headOut` (spec's `out`), `runLength`, `across` (via `Wide`).
- Hop arc height 0.3 of the runner's width; a called door opens in 0.18 s.
